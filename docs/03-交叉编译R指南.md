# 03 · 交叉编译 R 指南

按顺序执行（`build/all.sh` 串联）：

| 脚本 | 作用 |
|------|------|
| `05-get-ohos-sdk.sh` | 自动下载 Linux 版 OHOS SDK（已就绪则跳过） |
| `00-host-r.sh` | 编译 x86_64 Linux 的 host R（构建期脚本要用） |
| `10-deps.sh` | 交叉编译 pcre2/bzip2/xz/ncurses/readline（可选 openssl+curl、png/jpeg） |
| `20-f2c.sh` | host f2c + 交叉 libf2c.a |
| `30-build-r.sh` | 下载 R 源码 → 打补丁 → configure → make → install |
| `40-pack.sh` | strip、裁剪、注入 Rprofile.site、打 ustar tar、把 R/bin 拷进 HAP |
| `50-install-device.sh` | hdc 推到鸿蒙 PC 直接运行验证 |

## 30-build-r.sh 内部流程

1. 从 CRAN/清华镜像下载 `R-4.5.1.tar.gz`（版本在 `env.sh` 改）
2. 用最新 `config.guess/config.sub` 覆盖（识别 `*-linux-ohos` 三元组）
3. configure（关键参数）：

```
--build=x86_64-pc-linux-gnu --host=aarch64-unknown-linux-ohos
--enable-R-shlib            # 生成 libR.so，形态 B 需要
--with-x=no --with-tcltk=no --with-libtiff=no
--with-recommended-packages=no
--with-readline --with-libpng --with-jpeglib
--with-internal-tzcode      # 设备上没有 tzdata，必须内置
CONFIG_SITE=build/config.site.ohos
F77=FC=build/f77（f2c 包装）
```

4. configure 后把构建树 `bin/R`、`bin/Rscript` 替换成 host R 包装脚本
5. `make -j` → `make install` → strip → 打包

## 首轮调试清单（几乎必改的点）

R 的 configure 探测大量需要"运行测试程序"，交叉时无法运行。出现的报错和对策：

| 现象 | 处理 |
|------|------|
| `configure: error: cannot run test program while cross compiling` | 找到对应 `checking ...` 描述，在 `config.site.ohos` 追加 `ac_cv_*=yes/no` 固化结果。变量名规律：把 checking 句子去空格转 `r_cv_xxx` 或 `ac_cv_func_xxx`，可在 configure 脚本里 grep 该句子找到真名 |
| `checking whether ... works... ` 卡死 | 同上，追加缓存变量 |
| config.sub 报 `Invalid configuration` | 步骤 2 的覆盖没成功（网络问题），手工下载放到源码根目录 |
| make 在 `src/library/*` 阶段报 R 命令失败 | `bin/R` 包装没生效；`cat bin/R` 应指向 host R。个别步骤写死 `Rscript`，同样包装 |
| `undefined reference to s_cat/pow_di/gamma` | libf2c 没链接上：检查 `build/f77` 链接分支与 `$DEPS_PREFIX/lib/libf2c.a` |
| `f2c: command not found` | `sudo apt install f2c` 或跑 `20-f2c.sh` 的 netlib 自建分支 |
| musl 下 `error: 'backtrace' ...` 等 | 把缺失符号清单记入 `patches/README.md`，必要时写小型兼容源文件加进 `src/unix` |

调试心法：**每轮只解决 configure 的下一个 error，追加缓存，重跑**。configure 通过后
make 阶段问题大多是纯编译错误，改源码/补丁即可。收敛后把所有 sed/补丁固化进 `patches/`。

## 产物

- `build/out/r-ohos/` —— 完整 R 安装树（`lib/R` 即 R_HOME）
- `build/out/rhome-aarch64.tar` —— ustar 包，供 hdc 直跑与 HAP rawfile 共用
- `hap/entry/libs/arm64-v8a/librbin.so、libR.so` —— 沙箱禁执行时的备用执行体（见 docs/05）
