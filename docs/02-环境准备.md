# 02 · 环境准备

## 本机现状（已核查）

| 组件 | 状态 |
|------|------|
| DevEco Studio 5.0 / 6.0 | 已安装（程序本体在 `D:\Program Files\Huawei\DevEco Studio`，自带 HarmonyOS SDK/NDK） |
| WSL2 Ubuntu 22.04 | 运行中，gcc/make/perl 就绪 |
| Linux 版 OHOS SDK | **缺**（本机只有 Windows 版），WSL 交叉编译必须用 Linux 版 |

## 步骤 1：WSL 里装依赖

```bash
wsl -d Ubuntu
sudo apt-get update
sudo apt-get install -y build-essential gfortran perl curl tar xz-utils \
    zlib1g-dev libbz2-dev liblzma-dev libpcre2-dev libreadline-dev \
    f2c libf2c2-dev openjdk-17-jdk-headless
```

## 步骤 2：获取 Linux 版 OpenHarmony SDK（含 NDK）

两种途径任选：

1. **开源版（免登录，推荐）**：OpenHarmony 发布包附带 SDK
   `https://repo.huaweicloud.com/openharmony/os/<版本>/ohos-sdk-windows_linux-public.tar.gz`
   （可直接跑 `build/05-get-ohos-sdk.sh` 自动下载解压）
2. **官网版**：华为开发者网站 → DevEco Studio 页 → SDK 下载，选 Linux 版

解压后只需其中的 `native`（llvm + sysroot）。约定放到 `/opt/ohos-sdk`：

```
/opt/ohos-sdk/native/llvm/bin/clang
/opt/ohos-sdk/native/sysroot/usr/lib/aarch64-linux-ohos/libc.so
```

校验：

```bash
/opt/ohos-sdk/native/llvm/bin/clang --version | head -1
echo 'int main(){return 0;}' > /tmp/t.c
/opt/ohos-sdk/native/llvm/bin/clang --target=aarch64-unknown-linux-ohos \
  --sysroot=/opt/ohos-sdk/native/sysroot -D__MUSL__ /tmp/t.c -o /tmp/t && echo OK
```

> 注：HarmonyOS 商用 SDK 与开源 OpenHarmony SDK 的 native 部分同源（musl + llvm），
> 都能编 `aarch64-unknown-linux-ohos`。跑商用鸿蒙 PC 优先用官网 Linux SDK。

## 步骤 3：没有真机？用模拟器（本机已具备）

本机已下载 DevEco 模拟器镜像：`HarmonyOS-6.0.0/pc_all_x86`（鸿蒙 PC）与
`HarmonyOS-5.0.5/2in1_x86`。**除最终 arm64 真机验证外，全流程均可无真机完成**：

1. DevEco Studio → Tools → Device Manager → 用 pc_all_x86 镜像创建 PC 模拟器
2. 面向模拟器构建（x86_64）：

```bash
cd build && OHOS_ARCH=x86_64 ./all.sh     # 产物 rhome-x86_64.tar + libs/x86_64/
./50-install-device.sh                    # hdc 对模拟器同样适用（模拟器自启 hdc 目标）
```

3. HAP 的 `abiFilters` 已同时声明 arm64-v8a 与 x86_64，DevEco Run 直选模拟器即可
4. 拿到真机后：`OHOS_ARCH=aarch64 ./all.sh` 重出 arm64 包（源码层产物通用）

> 注意模拟器（x86_64）与真机（arm64）需各跑一次交叉编译；R 源码与补丁完全复用。

## 步骤 4：真机（鸿蒙 PC）连接

1. PC 上：设置 → 系统与更新 → 开发者选项 → 打开「USB 调试 / ADB/HDC 调试」
2. Windows 端 hdc 在 DevEco 里自带：`D:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe`
   （可加进 PATH）
3. 网络连接：`hdc tconn <PC的IP>:5555`；USB 连接则插线后 `hdc list targets` 应见设备

## 目录约定

构建脚本统一从 `build/env.sh` 读环境变量（`OHOS_NDK`、R 版本、产物路径等），
改版本/路径只需要改这一个文件。
